Run through `outputs/31x-cards-89-94-20261115/run-suite.ps1 -Suite 31x-irene`, supplying an immutable `-Candidate` for each supported profile. Use `-CheckArgs @('--isolate-telemetry')` where required by the beta native fixture.

Real native card wrappers, payment, seven-choice upgrades, SavedProperties, PowerCmd apply/remove/amount commands, pre/post attack hooks, and shared damage/critical arithmetic are retained. Attack visuals and the canonical HP presentation terminal are controlled. Tests do not start Godot or live multiplayer.

The suite executes the actual native Expose body with its production narrow callsite patch. Card cases cover pre-attack buffs and their whole-attack consumption; all-target Expose before damage; forced critical isolation; current-removal QED contribution; owner and combat separation; ordinary/native-extra/OD/personal energy receipts and replay cap.
