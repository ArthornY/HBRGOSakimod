# 30A class relic native checks

This standalone managed host loads an explicitly hashed production DLL against the original stable 0.107.1 and beta 0.113.1 runtime profiles. It does not launch Godot or copy delivered mod files.

The checks execute actual production phantom intents, canonical damage commands and shared damage arithmetic, native power application, capture/death and experience commit paths, merchant success envelopes (including removal-service cancellation), and native saved-properties JSON round-trips. Countdown, Madly Infatuated, Ecstatic Corridor, Distant Prayer, Lingering Life and native zero-to-positive HP revival routes are covered. Checkmate is checked across all segments of an attack, nested reactions, ordinary/inserted-turn receipts and expiration. Owner, legacy-mode and melted-relic isolation are checked.

The merchant entry's purchase body is controlled; the native wrapper and success hook remain real. The removal-service selection/payment terminal is controlled; its alternate stable envelope and beta common envelope remain real. Draw and energy-gain terminals record requested amounts. Creature scene insertion, animation, preview notification and prayer selection are controlled. The extra-turn token lookup supplies distinct tokens; it does not run a complete OD/personal coordinator. These checks do not establish visual rendering, live networking or actual selection UI behavior.

The host links existing effect fixtures and currently inherits 23 nullable warnings from those fixtures. Production SDK build results are recorded separately by the parent task.

Run `outputs/class-relics-95-99-20261116/30a/run-native.ps1 -Candidate <absolute DLL> -ExpectedSha256 <SHA>`. Use `-BuildHost` after changing the test source. Both runtime profiles run sequentially. Reports and an index are written only under the 30A output directory.
