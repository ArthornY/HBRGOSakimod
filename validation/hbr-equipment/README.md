# HBR 装备、饰品与手册商店验证

独立的 .NET 9 控制台项目，直接链接 `Core/Equipment/*.cs`，无需 Godot、游戏或额外 NuGet 包。

在此目录运行（PowerShell）：

```powershell
$env:NUGET_PACKAGES = 'C:/Users/ROG/.nuget/packages'
dotnet restore Checks.csproj --source 'D:/stsmod/Godot_v4.5.1-stable_mono_win64/GodotSharp/Tools/nupkgs' -p:NuGetAudit=false
dotnet build Checks.csproj --no-restore
dotnet ./bin/Debug/net9.0/Checks.dll
```

`master-snapshot.json` 是目录用到的 204 行 hbr.quest 主数据，日服和国服各一份，附完整响应的 SHA-256。日服的行提供数值，国服的行提供官方中文名和说明；被动技能另记下种类、元素、作用对象、`power` 和 Hit 数范围。

覆盖范围：

- 数据：每一行的星级、日文名、官方中文名和说明第一句、图标、属性数值、「+」栏数、芯片栏数，以及 GP 换算成金币的价格，都和快照逐项比对。高级吊饰国服还没上线，检查它们标为模组译名，图标用普通吊饰的图代替。
- 随机表与特效：每张原作随机表要么原样对应一张属性表，要么是耳坠的特效表（档位和权重保留，数值是被动的最大加成），要么是写明不做的元素表。固定被动按文档换算：戒指 4/5/6/8/10% → 出目 +10/12/13/17/20，属性对应牌的类型；门系列 25/50/75% → Boss 减伤 5/10/15%；远古项链的技能攻击力、破坏率上升量、防御力各 10%；初始 SP +3 → 每回合 1 点能量；★6 手环 → 完美打击。
- 贴图：`images/ui/hbr_equipment/sources.json` 里每个文件都存在，SHA-256 一致；每件装备的图标和商店界面用到的原作贴图都有记录。
- 换算：原作的属性和 DP 按档次 ×1.75 / ×1.9 / ×2.1。饰品、吊饰、芯片按星级（★1–2 / ★3–4 / ★5–6），增幅器按出售的幕（第三幕的大师只有 1 星，也是 ×2.1）；芯片的星级都和出售的幕一致；暴击率保留原作百分比。「+」栏每级为 1 点属性、20 DP 或 0.1% 暴击率，按所在饰品的档次换算，文字也一样。名称后的「+N」、描述的分组写法、吊饰炼金和装备页的换算说明。
- 规则：芯片栏随增幅器开放，换成槽位少的增幅器后，多出的芯片回到持有；装错栏会被拒绝；物品可以在栏位间移动。饰品 Lv. 按原作公式计算，吊饰栏按 Lv. 4/8/12/16/20/24 解锁，等级降低后锁住的吊饰回到持有。
- 「+」栏：按顺序解锁，消耗青绿琥珀之露，不能超过栏数；用阳石之露重抽只改选中的那一格；同一种子和计数器重抽结果相同。
- 命令：版本号过期会被拒绝；战斗中不能更换装备，也不能改已装备饰品的「+」栏，但可以购买；金币不足、非本幕货品会被拒绝；炼金结果确定且推进计数器；已装备的物品不能出售；领取凭据防止同一份奖励被领两次。
- 存档：完整往返，包括每张随机表的档位；缺失、损坏或架构版本不对的数据退回空状态；档位缺失时取第一行，越界时夹到表内；未知模板被丢弃，并清掉对应栏位；网络命令和奖励领取完整往返。
- 掉落：普通战约 35% 掉饰品，星级分布符合本幕权重；精英战必掉，且星级至少 ★2；Boss 必掉，另给两种素材，第三幕起还有约 50% 掉人工芯片；Gold Hopper 保留原作的青绿琥珀之露。
- ★6 与 Boss 物品的来源：★6 戒指和天命项链只从掉落获得；★6 耳坠、手环和加护、幸甚项链只从炼金获得，第三幕炼金约 35% 是 ★6；炼金做不出 ★6 戒指；Boss 约 40% 掉本幕的门系列手环，第二幕起约 30% 掉远古项链，普通战斗从不掉这两类。
- 耳坠曲线、特效合计和文字：四种耳坠每一档在 0～15 段时的加成，都和主数据被动的 `power`、Hit 数范围线性插值一致，10 段的两端是精确值；一套 ★6 配装的特效合计、属性合计、「+N」、饰品 Lv.、每件的说明文字和合计文字。
- 卖价：每一幕炼金能做出的每一件饰品和吊饰，各表最高档、「+」栏全满时，卖价仍低于当幕的炼金价。
- 商店：每幕的增幅器货架对应原作的章节商店，芯片按幕分档，人工芯片不出售。
- 校准（`Calibration.cs`）：模拟玩家跑 1000 局，掉落、商店、炼金和「+」栏都调用生产代码，按各幕战斗的平均伤害倍率检查。条件见 `docs/hbr-equipment.md`「校准」：每幕 6 场普通战、2 场精英战加 Boss，点数全加疯狂，入会仪式按疯狂 +8，金币按三幕不花钱约 2000 校准。花一半金币时，普通战平均 ×0.9～1.2、精英 ×0.65～0.95、Boss ×0.6～0.85；全部金币时 Boss 不超过 ×1.1；金币多的不会比金币少的弱；同一种子结果相同。运行时会打印三幕的数字。

检查只覆盖纯逻辑。战斗中的伤害、破坏率、OD 和出目加成由 [装备原生验证](../hbr-equipment-native/README.md) 覆盖；属性、DP 上限、暴击率、奖励界面、回合开始的能量和完美打击，需要另跑原生套件，或者进游戏实测。
