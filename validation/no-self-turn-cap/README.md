# 无我梦中：反噬单回合预算

直接检查实际编译模组的 `NoSelfInDreamPower.AfterDamageGiven`，不另写一套反噬公式。原样 stable 0.107.1 / beta 0.113.1 原生模型负责同阵营目标查询、DamageResult、能力和回合对象；仅隔离 Godot Flash/logger、遥测和最终场景伤害叶。

生产语义：原有每次对敌伤害的1/100向下取整；每名活友方（原生同阵营查询包含本人）各自每回合累计送入正常伤害流程的反噬，不超过其当下最大HP的25%向下取整。格挡、DP、减免正常参与，不退款预算。使用 exact LargeHealth 最大值。绯刀流豁免保留。只约束本能力反噬，不限制该单位遭受其他来源的伤害。

预算挂在 combat / holder 而非能力对象，防同回合能力移除重加绕过。相同 DamageResult 身份只结算一次。原生轮数、side、玩家回合计数和现有 OD / 个人额外回合 token 共同定位回合；退出额外回合回到普通回合时继续使用原预算。一次事件在 await 前预留全部目标的预算，避免异步重入超限。最大HP临时变动后按当下上限限制剩余额度；已经发生的伤害不回滚。

覆盖累计上限、不同HP、floor、幂等、重加、下一回合、额外回合与普通回合恢复、side/round、异步重入、绯刀流、死队友、非本人伤害、友方伤害、到期能力和超Int32召唤物HP。额外回合验证使用真实 session 类型，但不声称实机联机队列或入场流程已经验收。末端伤害叶只记录送入量；实际HP/DP/格挡损失由既有流程负责，本宿主没有伪造资源处理通过的结论。

