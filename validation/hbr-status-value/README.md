# Enemy status value presentation

```powershell
dotnet run --project validation/hbr-status-value/Checks.csproj -c Release
```

The fixture directly links the production geometry helper. It checks right-edge
alignment, DP clearance, ordinary and layered HP/DP layouts, gauge thickness,
and collapsed widths. It also checks the updated manual/document terminology,
preserved player attribute names, and the caption's live enemy-parameter getter.
The JSON result includes the layout source hash. No Godot or rendered UI runs.
