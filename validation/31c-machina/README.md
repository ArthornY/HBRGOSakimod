# 31C 魔界骑兵与魔王使魔羁绊验证

此套件绑定编译后的模组 DLL 和 stable/beta 原生依赖，执行真实 `AttackCommand.Execute`、原生攻击回调、Ritsu managed action 序列化与派发、HBR 公共伤害/暴击/破坏率计算、原生能力施加及 DP 打破回调。成员牌 fixture 是仅在验证程序内注册的六种模型，不会进入模组内容。

覆盖：

- 永久同持有者不同成员计数，2/4/6 档位各自的本场使用次数与重置。
- 单一六段全体攻击的 1:1:1:1:1:5 权重、原生必暴击、通常力量和增益、大连击整组重复、一次攻击增益消耗，以及嵌套反应的隔离。
- 原作整次破坏系数 6：默认系数为 3，内部比例为 2；普通目标系数为 2 时，六段 HP 命中合计增长 12，不能变成 36。
- 暂时畏惧刷新，6 人档永久叠层，混档联机共享敌人能力时不降级、不免费叠层，Artifact 真实拦截，灾厄共同降低状态值。
- 同一序列化请求不可重用次数，执行时重新验证持有者/出牌阶段；两个不同成员档位的原生玩家各自消费账本，原生任务异常/取消不退次数且释放执行租约。
- 魔王与使魔：同持有者永久二卡才激活；山胁之后每张丰后均获得标准伤害增幅；丰后的实际 DP 打破事件只记录精确目标，排除已处于 Break、未打破、其它来源和无来源移盾。
- 双人羁绊的普通、敌方、OD 和个人额外回合账本彼此隔离；返回普通回合保留先前记录。

樱庭升级与恢复覆盖：同持有者的任意实现 `IActiveDuoBond` 的生效遗物自然纳入恋爱占卜，不使用三遗物白名单；Fortune 复用正常能力掷骰，阈值 47/48 与原生优势及加成路径；玩家、小萤、30A 本体和幻影、Kozue 灵体逐池回复，Disabled、LastStand、120% 真实可消耗 DP 与继承 SavedProperties/Fill，以及标准正负增益的时长和独立份数。抽牌仅校验真实命令请求，消耗校验原生关键词声明，出牌包装与最终牌堆动画不在本套件范围。

## 运行边界

终端伤害的 HP 写入、画面/音效/历史日志受控；DP 验证调用生产 `TryAbsorb` 与 `AfterDamageReceived`。套件没有启动 Godot，没有打包，也没有上传。真实网络传输、双方客户端同步、鼠标/键盘/手柄按钮操作和最终画面需要游戏验收。生产构建由整合者单独执行；本项目引用的其它验证 host 中已有 nullable 警告不代表生产构建警告。

报告位于 `outputs/31c-machina-20261114/{stable,beta}/report.json`，其中记录实际 DLL SHA-256、运行依赖档位、逐项断言和边界。必须分别编译并顺序运行两档，不能并发构建同一验证项目的不同档位。优先使用对应 `outputs/31b-monsters-20261114/{profile}/latest-candidate.json` 指向的不可变 DLL。

运行：`powershell -File validation/31c-machina/run-suite.ps1 -Profile both`。该脚本只编译验证项目，读取当前两个不可变候选，不编译生产或调用 Godot。
