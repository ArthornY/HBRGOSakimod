# Local upgrade-story receipts

This independent pure .NET host links the actual production local-file implementation and playback enum. All test files live below an injected temporary directory, never Godot's user data. It covers the three perspectives and levels 1–7, run partitioning / reconstruction, normalized identity, duplicate claims, cross-run seen state, abandoned-start semantics, invalid JSON/version protection, write-failure rollback, temporary-file cleanup and parallel claims.

The static facade's configuration guard and stable native RunManager identity are tested separately by `validation/memory-garden-upgrade-story-native`. That probe loads the actual candidate and the existing 31O fixture's engine setup, supplies a temporary file backend, and checks original stable / beta runtime contracts without a Godot scene or real save load. It does not claim to test the reader, upgrade queue, rendering or network isolation.
