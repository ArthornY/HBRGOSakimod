# 正面能力：专属增幅、原作效果与连击

原作攻升、防升、暴击增益的属性公式、份数和时限统一见[通用效果说明](hbr-effect-framework.md)。本页的伤害增幅属于专属成长机制，不套通用两份上限或属性倍率。

## 伤害增幅

「伤害增幅」与原能力「超越自我」使用同一个百分比池，每点提供 1% 伤害增幅，保留小数精度。不同来源的增幅相加，然后进入现有伤害计算流程。

- 卡牌「超越自我」名称保留，继承的幻影增伤加入「伤害增幅」。
- Boost Up、Hello world 的相关升级效果使用同一能力。
- 旧能力 ID 和旧 `DamagePercentData` 字段仍可读取；再次施加时并入已有实例，避免增加第二个能力图标或重复结算。
- 仅合并这两个能力。具有独立到期规则的回合增伤仍保留自己的生命周期。

## 连击

| 能力 | 每次攻击的效果 | 每次获得的层数／可生效次数 |
| --- | --- | --- |
| 连击（大） | 段数 ×2 | 1 |
| 连击（中） | 段数 +3 | 3 |
| 连击（小） | 段数 +1 | 5 |

每种能力最多保留两个独立实例，每个实例的层数表示剩余次数，均参与同一次攻击。该种少于两个实例时新建；已有两个时，新实例替换剩余次数较少者并使用新次数；不把次数加到原实例上。连击同种强度相同，因此依照通用原作规则以剩余次数打破平局。每次完整攻击有实际命中后，各生效能力分别减少 1 层；一次多段或群体攻击只扣一次。格挡抵消全部伤害也算命中；无命中、预览、无增益伤害、幻影的攻击转格挡及浮游炮的反应伤害不扣层。

所有连击实例先加段数，再按每个大连击分别翻倍。因此原本 1 段、同时具有三种连击时为 `(1 + 3 + 1) × 2 = 10` 段。效果属于实际持有者，角色、幻影和浮游炮分别计算。浮游炮每个攻击阶段算一次攻击；只有成长或格挡的阶段不消耗次数。

复用既有攻击段数与 AttackContext 流程，幻影与浮游炮直接攻击在整次攻击外预留、结束时消费，不增加逐帧检查。取消或异常退出释放预留，避免锁住后续攻击。

刚射、刀舞、龙箭等原先逐段建立攻击命令的牌改为完整多段攻击。刮奏保留各目标独立的基础伤害，连续斩击保留逐段重算伤害；异值追击与格挡转伤害保留各段的计算上下文。整次出牌不会因这些内部拆分多扣连击层数。

### 后续效果的调用约定

```csharp
await HbrComboPower.Grant<HbrComboLargePower>(context, target, source, card);
await HbrComboPower.Grant<HbrComboMediumPower>(context, target, source, card);
await HbrComboPower.Grant<HbrComboSmallPower>(context, target, source, card);
```

以上分别给予 1、3、5 次；重复获得按上述双实例规则分配。原生 `PowerCmd.Apply` 和 `ModifyAmount` 的数值仍表示层数，因此翻倍等已有计数操作不会再次乘以持续次数。

双剑形态自带一个无限次的虚拟连击（中），攻击增加3段，不占两个实例名额。追击额外增加1段，仅对本次攻击生效，不另行获得五次的小连击。二者与真实连击实例先相加，再按大连击翻倍。每个实例独立显示图标，右下角显示加段／翻倍效果，右上角显示剩余次数。

## 双剑与追击

双剑形态取消原有的回合能量、自动复制、全局伤害75%和格挡150%。手动打出的普通攻击使紧接着的手动攻击获得追击，之后下一张恢复普通攻击，按普通／追击交替。手动打出非攻击牌重置；自动牌既不推进也不打断，也不获得追击。

追击的实际能量消耗减半并向下取整，X费除外；该次攻击增加1段，最终伤害乘75%。卡农使追击按100%伤害结算，升级仍保留固有。费用、剑心补付与卡面显示共用同一报价；普通重放保留该实体牌的追击快照，不多次推进状态。

回忆、模仿和未完等来源的复制与X费用记录仍保留，统一由CardCopyContextHelper保存；残心的复制不再被双剑专门视为弓牌。相生、自在对其他来源复制的原有限制保持。
