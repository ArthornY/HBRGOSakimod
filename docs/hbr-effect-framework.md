# HBR 原作效果通用规则

本页记录2026-11-14实现的当前规则。**只统一能对应到原作效果的能力**；专属伤害增幅、灵魂之力、绯刀流、永久成长和掷骰系统保留自己的机制，不套两份上限或属性倍率。原版Weak／Vulnerable保留原模型、固定比例、原生时限和联动，不替换成HBR攻降／防降。

## 强度公式

效果强度与剩余次数／时间分开保存。下列数值均为百分数的百分点，`B`是技能给定的固定基准，`E`是目标当前状态值：

```text
增益 = B × [1 + (参照属性 − 100) × 0.0002]
减益 = B × [1 + (参照属性 − E) × 0.001]
```

不截断正负属性差，不设效果上下限，不使用原作power上下端或diff_for_max阈值。负效果百分比也可保存、显示和参与计算。资源不能为负、最终伤害非负整数、概率的0～100%范围等物理边界仍由对应系统处理，并不是给效果强度加下限。

| 效果 | 参照属性 | 当前基准／定值 |
|---|---|---|
| 攻击力上升 | 智慧 | 技能给定，如Live为30% |
| 防御力上升 | 智慧 | 技能给定 |
| 攻击力下降、防御力下降 | `(2×智慧+运气)/3` | `15% × 1.25^(修改器数−1)` |
| 脆弱 | `(智慧+2×运气)/3` | `30% × 1.25^(修改器数−1)` |
| 精神下降 | 智慧 | 50% |
| 智慧下降 | 固定，不吃属性 | 80% |
| 暴击率上升 | 智慧 | 若向流星歌唱为50% |
| 暴击伤害上升 | 固定，不吃属性 | 若向流星歌唱为50% |
| 灾厄、士气、连击 | 固定层数／等级／段数 | 不做百分比属性换算 |

修改器数属于技能基准，不表示效果份数或持续回合。卡面未选目标时显示基准，选定目标后显示本次计算结果；实际施加保存完整精度，后续属性变化不会重算已有份数。显示可保留一位小数，不将显示舍入值写回战斗。

同类攻击力上升、防御力上升的活跃百分比相加；既有攻降、减防、脆弱的乘区关系保留。脆弱的伤害收益仍要求Break。天然暴击与掷骰大成功分开判定：原作暴击伤害为`1.5 + 暴伤增幅÷100`，50%暴伤增幅对应2倍，两个50%对应2.5倍；不会将原有1.5倍再重复乘1.5倍。暴击率增益加到天然概率，预览不抽随机数。

### 改前、改后示例

以下固定运气100、目标E150、修改器数1；“智慧200”仅改变智慧，方便看出不同权重。表内是效果百分比，不是最终伤害。

| 效果 | 改前：智慧100／200 | 改后：智慧100／200 |
|---|---:|---:|
| 攻击力上升，基准30% | 固定30%／30% | 30%／30.6% |
| 防御力上升，基准30% | 固定30%／30% | 30%／30.6% |
| 攻击力／防御力下降，基准15% | 15%／15.25% | 14.25%／15.25% |
| 脆弱，基准30% | 30%／30% | 28.5%／29.5% |
| 精神下降，基准50% | 固定50%／50% | 47.5%／52.5% |
| 智慧下降 | HBR适配原为25% | 固定80%／80% |
| 暴击率上升，基准50% | 新能力 | 50%／51% |
| 暴击伤害上升，基准50% | 新能力 | 固定50%／50% |

攻降／防降／脆弱改前对负属性差取0，现在不取0。旧非HBR局的智慧降低格挡25%、精神增加受伤25%的等效适配仍保留。

## 份数、计时和消费

- **Default**：每种最多两份。每次获得独立一份，同数值也不合并。第三份不低于较弱者时替换较弱者，强度相同时优先替换剩余最少者，并使用新效果的完整时间／次数；更弱则不生效。
- **Only**：精确对应尚未完成验证，目前明确回退为Default，不冒充已完整实现原作“单独发动”。
- **None**：份数不限。士气作为原作等级资源使用总等级计数，最高10级、整场保留；每级固定增加六项战斗属性各5点，先加基础点再应用百分比。
- **Count**：完整攻击有命中结果后减一次，不按段数或目标数重复扣。格挡完全抵消仍算命中，空结果和异常不消费。直接循环、浮游炮和幻影在完整攻击scope结束后统一消费；通用技能公式的独立持续伤害／反伤命令也按一次完整命令消费对应次数。原版一次性攻击增益仍看原生命令标记。
- **PlayerTurnEnd／EnemyTurnEnd**：固定我方／敌方回合结束计时，不等同于持有者回合。PlayerTurnEnd检查持有者是否参与，队友个人额外回合不会减少自己的时限。既有额外回合正面时限冻结和伤痕的衰减保护继续生效；Count消费不冻结。
- **EnemyTurnStart**：固定敌方回合开始计时，眩晕使用1次；不复用回合结束的退出条件。
- **OwnerTurnStart**：持有者参与的本方回合开始结算后减一次。持续DP伤害、持续伤害使用4次；能量流失等能量重置后扣除再计一次。此转换保留用户指定的4次实际扣除，避免施加敌方回合末先减为3次。
- **Eternal**：本场战斗保留，不按回合或攻击消费。

每份一个图标，右下角是强度，右上角是剩余时间／次数，Eternal显示∞。没有持有者的手册词条使用独立的静态参考说明，不读取某份战斗中的强度或时限；攻升、防升、精神下降、智慧下降及两种暴击增益均提供对应参考文案。翻倍对现有份数操作，强度和剩余时间各翻倍，不重新计算属性；被免疫阻挡时不能只改变其中一半。

默认值按冻结技能数据中相应效果的常见行选择；具名技能只有核实到**同种效果部分**才覆盖。用户明确指定的强度、3／4回合等优先于原作原数值。

2026-11-14 敌方状态统一为每次施加独立一份，None不参与两份替换。封印、束缚、眩晕、混乱是开关类：有任一有效份就生效，多份不加重；束缚／眩晕共同只扣一次能量，HBR为[EE]（2026-11-15由[E]改定），旧模式保留[E]。病毒的百分比相加（DP上限最低0），持续DP伤害和持续伤害各份分别扣除，幻惑层数相加并优先消费最早到期的一份。每份图标右上是时限，右下是百分比或层数；开关类不显示强度。敌方自己的攻升、防升强度和原有两份政策不改。

冰华的模组额外脆弱、迅雷风烈的模组脆弱没有对应的原作Fragile部分，使用通用1回合，不把原作DefenseDown的退出条件移植到Fragile上。退魔之矢与`MKiryuSkill01`咒怨之矢的别名尚未核实，全身铳击未匹配到确切原作行，均使用通用默认，不伪造对应。若向流星歌唱原作两种暴击部分均固定；模组暴击率采用用户要求的智慧公式，暴伤保持固定。

## 2026-11-15 敌方减益强度修订

仅HBR模式中真正敌方施加者的六只表怪使用原作part上限基础：钻石眼魔／花冠利刃／阿拉克尼的防降、触手巨蛇的攻降30%；BarrelWalker防降25%；磐石异蟹攻降、防降各20%。DeadlyEnemies档在此基础上乘1.25，再按共享属性公式结算，None政策和原有EnemyTurnEnd 2／4不变。玩家幻影保留15%×1.25^(修改器−1)与原默认档案。

特殊Boss公共入口的敌方攻降、防降基础分别为25%、50%，原时长、99整场、Default限制和属性公式不变；玩家幻影施加仍为15%。显式卡牌／Boss基础优先于表怪自动基础，不改变原版Weak／Vulnerable，也不全局替换卡牌基础值。

病毒／幻惑／混乱的玩家持有者分别按自身回合结束2／2／3次退出；敌方或幻影持有者不改。HBR普通外壳Break缩短为房型2／3／4回合，旧模式保留3／4／5，与通用减益时钟独立。

## 敌方E与伤害边界

敌人使用一个状态值E，不伪造六个已保存属性。需要智慧的效果读取这个标量；智慧下降只改变该效果的智慧参照份额：`E × (非智慧权重 + 智慧权重×(1−智慧下降总量/100)) ÷ 总权重`，不降低全局E或物理攻击。HBR敌方格挡使用`1−智慧下降总量/100`；精神下降保留旧等效标定，但读取实际总强度：受伤系数`1+精神下降总量/200`。同类总量只结算一次，这是尖塔资源适配，不宣称原作敌人拥有六项独立属性。

我方默认伤害属性为力／器用1:1，DP／HP不切换权重；已核实迅雷风烈、梦幻泡影、邪眼海浪斩击用力2／器用1。敌方伤害保留技能声明的防御权重，使用单一线性系数`1+(E−防御参照值)/140`，正威力最低1，不再有上端封顶。敌对敌／自身伤害以目标E作为防御参照，也不制造六项属性。

按实际格挡、伤害等产生的world数值在入口保留原值，在共享曲线处只归一化一次：我方单位1000、敌方单位100；无攻击者的world量保持资源单位。已经完整结算的追加伤害、固定HP成本、百分比生命伤害等明确例外不重复进属性公式。原生命令归属和原始标记不改；效果技能的给予者用于属性与模组增减伤的算术视图，例如由玩家施加、原生dealer为空的持续伤害能正确获得该玩家攻升并消费一次。

## 保存与验证

新模型单独保存冻结强度、退出条件、份数限制和初始时间覆盖值。旧攻升／防升的Amount是百分比、RemainingTurns是时限，预览只读，首次生命周期操作才迁移，避免30%变成30回合；旧脆弱的原始修改器存档继续使用既有迁移，不在打开界面时改写。

实现入口为`HbrEffectProfile`、`HbrEffectRules`、`HbrEffectApplication`与`HbrEffectPower`，既有百分比减益复用同一规则。独立验证项目位于[通用效果检查](../validation/hbr-effect-framework/Checks.csproj)，覆盖原生施加、替换、消费、固定侧计时、老保存形状、克隆、翻倍、E适配及world单位归一化。结果放在`outputs/hbr-effect-framework-20261114/{stable,beta}/framework-report.json`，以报告实际DLL哈希为准；这是托管源代码验证，不代替游戏界面、完整存档或双端联机验收。

## 31A 与心眼（需求28～37）

心眼使用基准42%的知性增益，每份Count 1、同类最多两份，第三份按共同规则替换。与攻击力上升的百分比相加后再参与伤害，不再改变掷骰。一次攻击牌的多目标、多段和多个伤害命令共用消费标记，嵌套打出的其他牌不会借用已被父牌消费的份数。司的额外回合虚拟心眼单独计算，不占名额、不消费虚拟份。

31A由希的下一次减益加成在统一施加边界对基准数值乘1.3，之后按属性计算；原版减益保留其模型、施加钩子和取整。一次施加的多个目标共享一个加成，重复施加与不同种减益各使用下一次。被Artifact完全阻挡的施加释放预留。整场且不占名额的攻升、防降和脆弱使用None/Eternal显式profile，普通份不会替换它们。

本批卡牌升级不做旧存档适配；此前已完成的兼容逻辑不回溯删除。相关真实托管行为、台词数据、资源与两版编译证据见`outputs/31a-28-37-20261114/`。


## 敌人行动附加机制（2026-11-15，M10–14）

挑衅使用Default／EnemyTurnEnd 2，约束玩家单体Attack的原生目标校验；狂暴是同一攻击力上升桶内的专用Only／Eternal实例，基础100，只在同伴异蟹真实死亡时领取一次，不能靠重复死亡通知累加。猫角兽的群体基础200攻升由猫角兽作为applier，全部受益者使用相同的施加者属性公式、Default／EnemyTurnEnd 2，沿用普通攻升两份政策。

三柱OD检测与Barrel／钻石眼魔倒数属于敌人行动规则标记，不改通用效果的份数、上限或时钟。它们和异议之门倒数通过事件更新意图；暂停行动保存已选原招的前后游标与一次标记，UI刷新不重新掷骰。详见[当前敌人追加机制](hbr-act-rosters.md)。
